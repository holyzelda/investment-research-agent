# 联络线功率趋势设计

**日期：** 2026-07-21  
**状态：** 已确认，待实施计划

## 目标

为联络线地图右侧的已选线路详情补齐真实功率趋势。数据来自已导入的 `ir_tie_line_power` 宽表；趋势展示不改变地图线路的静态起讫箭头、颜色、线宽、顶部统计或潮流语义。

## 范围与边界

- 功率趋势仅展示在右侧已选线路详情面板；切换线路时重新查询该线路。
- 页面初次进入时没有用户明确选择线路，维持现有静态推荐详情行为；仅在存在已选线路时加载趋势，避免把推荐线路误认为用户当前选择。
- 不新增实时刷新、潮流方向/强度、地图动画、顶部最高最低 MW 指标或预聚合表。
- 不改 `ir_tie_line_power` 表结构、导入接口或 DDL。
- 不新增认证、路由守卫或外部地图请求。

## 时间范围与聚合口径

所有范围以**自然日昨天**为结束锚点；当天与未来日期均不可查询。

| 选项 | 查询范围 |
|---|---|
| 昨日 | 昨天至昨天 |
| 7 日 | 昨天向前含当天共 7 个自然日 |
| 30 日 | 昨天向前含当天共 30 个自然日 |
| 90 日 | 昨天向前含当天共 90 个自然日 |
| 自定义 | 用户确认的闭区间，结束日期最大为昨天 |

输出恒为 96 个 `15 分钟`时刻，从 `00:15` 至 `24:00`：

- 单日范围：每个时刻对应当天原始功率值。
- 多日范围：每个时刻取范围内同一时刻的所有**非空**功率值算术平均。
- 空值不参与平均；若一个时刻在全区间均为空，返回 `null`，前端折线在此处断开。
- 没有任何日期记录时，仍返回 96 个 `null` 点，不把无数据表示为零功率。

## API 契约

新增只读接口：

```text
GET /ir/tie-lines/{lineId}/power?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD
```

成功响应的 `data`：

```json
{
  "lineId": 12,
  "startDate": "2026-07-14",
  "endDate": "2026-07-20",
  "dataDateCount": 7,
  "points": [
    { "time": "00:15", "powerMw": 1234.56 },
    { "time": "00:30", "powerMw": null }
  ]
}
```

约束：

- `startDate` 和 `endDate` 必填。
- 格式错误、开始日期晚于结束日期、任一日期晚于自然日昨天，返回既有统一 HTTP 400。
- 线路不存在返回 404。
- 功率记录以 `line_id` 精确关联，不按线路名称或电压等级回查。
- `dataDateCount` 是查询范围内实际存在功率行的日期数。
- 响应继续使用 `{code, msg, data}` 外壳；业务字段使用 camelCase。

## 后端设计

在 `app/modules/tie_line_map/` 按既有方向实现：

1. 领域层定义固定 96 点的功率趋势值对象。
2. 应用层服务先验证线路存在及范围合法，再按 `line_id`、闭区间查询 `TieLinePowerORM`；逐列忽略 `None` 求平均，构造稳定的 96 个时刻。
3. 接口层解析日期参数，映射校验异常为既有 `ValidationException`，并序列化为 camelCase。
4. 复用现有 ORM 宽表与服务模块；不引入预聚合、缓存、回退查询或第二数据源。

## 前端设计

### 组件与状态

- `src/api/tieLine.js`：增加功率趋势查询薄封装。
- `src/store/modules/tieLine.js`：集中维护当前趋势线路 ID、已确认日期范围、结果、加载与错误状态；使用递增请求序号，使旧请求响应不能覆盖当前线路或范围。
- `TieLineDetailPanel.vue`：移除“功率时序数据未接入”占位；仅在 `line` 存在时嵌入趋势区域。
- `TieLinePowerRange.vue`：昨日、7 日、30 日、90 日快捷按钮，以及自定义日期范围弹窗；自定义确认才更新范围并查询，取消保留已成功展示结果。
- `TieLinePowerTrend.vue`：趋势图、加载骨架、空态、错误提示和重试按钮。

### 图形规则

- 使用单序列 ECharts 折线图，横轴恒为 96 个时刻、纵轴为线性 MW 轴；不使用双轴。
- 区间辅助文案：单日展示“YYYY-MM-DD · 单日功率”；多日展示“开始日期 至 结束日期 · 各时刻平均功率（N日）”。
- 线宽 2px，`connectNulls: false`，使用十字准星 tooltip 展示时刻与功率。
- 单序列不展示冗余图例；标题承担系列身份。
- 重用 `useEcharts` 管理生命周期。ECharts canvas 颜色通过 `xcVar()` 读取现有 XC token；组件 CSS 只使用 `var(--xc-*)`，不写硬编码颜色。

### 状态规则

- 切换已选线路时清空上一条趋势并立即加载新线路数据。
- 快速切换线路或范围时，只有当前请求序号对应的响应可以更新状态。
- 无任何数据：显示“该线路在所选日期范围内暂无功率数据”。
- 接口失败：趋势区显示错误及重试，静态线路资料继续可用。
- 加载中：显示与图表区域等高的骨架屏，避免面板布局抖动。

## 测试

### 后端

1. 单日返回原始 96 时刻值。
2. 多日按时刻忽略空值计算平均。
3. 全区间某时刻为空时返回 `null`。
4. 没有记录返回完整 96 个 `null` 点和 `dataDateCount: 0`。
5. 不存在的线路返回 404。
6. 缺失参数、日期格式无效、日期倒置、当天或未来日期均返回 400。
7. 验证响应字段 camelCase 且时刻数固定为 96。

### 前端

1. 已选线路默认请求昨日范围。
2. 7/30/90 日正确按自然日昨天反推并包含昨天。
3. 自定义日期选择禁止当天/未来；仅确认后请求，取消不改变已展示结果。
4. 切换线路重新请求，旧异步响应不能覆盖当前趋势。
5. 图表使用固定 96 点，单日/区间文案与 tooltip 正确。
6. 骨架、无数据、部分空值断点、失败与重试均正确展示。
7. 现有静态详情、地图选择、线路筛选回归通过。
