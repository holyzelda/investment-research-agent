# 首次结果项目参数可编辑设计

## 背景

当前调整参数模块将首次结果（V1）的整个“项目定义”分区锁定为只读。这会同时禁用省份、节点、储能装机功率和装机容量。业务要求调整为：首次结果中仅省份不可改，节点、功率与容量应可直接修改并重新测算。

## 范围

本变更只调整参数面板的首个版本编辑规则与对应的需求制品、测试。

不改变：

- 会话内省份不可变、更换省份需新建会话的约束。
- 重新测算创建新任务和新版本、不覆盖历史版本的机制。
- `basics`（节点、功率、容量）和 `param_overrides` 的既有请求契约。
- 后端针对节点、功率、容量或日均充放电次数变更时刷新现货价格的既有逻辑。

## 目标行为

调整区项目定义字段在所有结果版本中遵循以下规则：

| 字段 | V1 | V2 及以后 |
| --- | --- | --- |
| 省份（`province`） | 只读 | 只读 |
| 节点（`node_name`） | 可编辑下拉（当前省存在站点时） | 可编辑下拉（当前省存在站点时） |
| 储能装机功率（`power_mw`） | 可编辑数字输入 | 可编辑数字输入 |
| 装机容量（`capacity_mwh`） | 可编辑数字输入 | 可编辑数字输入 |

用户修改节点、功率或容量后点击“重新测算”，前端继续通过现有 `basics` 载荷提交修改值。后端创建 V2（或后续版本），历史版本保持不变。

## 实现边界

- 前端锁定判断改为只锁定参数字典声明为 `control: 'fixed'` 的字段；由于 `province` 为固定字段，它将继续只读。
- 保留 `firstCalc` 作为组件输入兼容项，除非实际检查发现其没有其他使用者；不为这次局部规则变更做无关重构。
- 更新 `paramAdjust` 单元测试和 `ParamAdjustPanel` 组件测试，明确断言 V1 中节点、功率、容量可编辑且省份只读。
- 更新 active spec 的锁项表述及其执行合同，确保今后实现与验收遵循新规则。

## 错误与回归

输入框仍沿用现有数字精度处理；空节点仍按既有 `null` 提交。省份不进入可编辑控件，因而不会产生会话内换省请求。测试应继续覆盖重新测算的 `basics` 载荷，保证项目字段修改能抵达既有后端重算逻辑。
