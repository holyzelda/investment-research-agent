# 联络线线路档案与功率趋势重设计

**日期：** 2026-07-21  
**状态：** 已确认，待实施

## 目标

将联络线地图右侧详情从“字段卡片 + 趋势区”优化为连续分析侧栏中的“线路名片 + 微型线路图 + 数据带 + 功率趋势”，提升长名称可读性、趋势图辨识度与整体信息层级。

## 范围

- 修改 `TieLineDetailPanel.vue` 的线路档案结构与样式。
- 修改 `TieLinePowerTrend.vue` 的空态图表与颜色来源。
- 保留当前页面、Store、API 与后端数据结构，不重写地图页。
- 不新增外部依赖，不新增业务状态到 Store。

## 线路名片

顶部展示：

- 弱化眉题：`线路档案`。
- 醒目的线路名称，允许自然换行，不使用省略号。
- 右上角电压等级标签。
- 线路类型说明：
  - `voltageText` 包含 `±` 或线路名包含 `直流` 时显示 `跨区直流输电线路`。
  - 其他情况显示 `跨区交流输电线路`。

## 微型线路图

起终点改为微型线路图：

```text
● 锡盟换流站 ─────▶ ● 泰州换流站
  内蒙古自治区        江苏省
```

规则：

- 起点和终点各占独立弹性列。
- 换流站名称与行政区名称完整显示，允许自然换行，禁止 `text-overflow: ellipsis`。
- 中间连线、箭头与端点使用当前选中线路的强调色 token。
- 右栏较窄时切换为纵向线路图，仍完整显示名称。

## 数据带

删除重复字段：

- 起始区域。
- 电压等级。

将额定容量、线路长度、投运年份展示为三列数据带：

```text
额定容量        线路长度        投运年份
8,000 MW       3,584.9 km      2017
```

样式规则：

- 不使用外框、背景卡片或阴影。
- 指标之间仅使用短竖向分隔线。
- 标签使用 12px 次级文字。
- 数值使用 17–20px、600 字重和 `.xc-num` 等宽数字。
- 数值允许换行，不省略。

## 数据口径入口

数据口径由长段落改为单行轻量入口：

- 默认显示摘要与“展开”。
- 点击后展示坐标基准、数据说明和来源备注。
- 再次点击收起。
- 没有任何口径字段时不显示。
- 内容允许自然换行，不省略。

## 功率趋势

功率趋势与线路档案处于同一连续侧栏中，仅使用一条细分隔线划分模块，不嵌套卡片。

颜色规则：

- 地图选中线路颜色、微型线路图颜色、趋势曲线颜色保持一致。
- `TieLineDetailPanel` 将当前 `accentToken` 传给 `TieLinePowerTrend`。
- ECharts 使用 `xcVar(accentToken)` 读取运行时颜色。

空态规则：

- 没有真实功率数据时不绘制模拟曲线。
- 保留坐标区域、零轴。
- 若有额定容量，绘制额定容量虚线。
- 图表中央显示：

```text
暂无实时功率数据
数据源尚未接入
```

## 长文本规则

以下内容禁止省略：

- 线路名称。
- 起点换流站。
- 终点换流站。
- 起点行政区。
- 终点行政区。
- 数据口径摘要与展开内容。

相关区域不得使用 `overflow: hidden`、`text-overflow: ellipsis`、`white-space: nowrap` 组合截断文本。

## 验证

- 更新详情面板测试，验证新结构、删除重复字段、数据带、数据口径展开、长文本不省略。
- 更新趋势组件测试，验证强调色 token 进入曲线/空态参考线，空态仍有坐标区域但无模拟曲线。
- 运行定向 Vitest、前端构建，并启动页面检查实际效果。
