# 联络线右侧详情布局优化设计

**日期：** 2026-07-21  
**状态：** 已确认，待实施

## 目标

优化联络线地图页面右侧“线路档案”和“功率趋势”区域的可读性与可点击性，扩大右侧详情栏实际内容宽度，使功率趋势图不再过窄，同时保持地图为页面主体。

## 范围

- 调整 `views/tie-line/index.vue` 的主体网格布局。
- 优化 `TieLineDetailPanel.vue` 的内边距、标题区和指标卡片响应式表现。
- 优化 `TieLinePowerTrend.vue` 的日期按钮区域和图表宽度表现。
- 不重写页面，不改变数据结构、API、Store 或地图绘制逻辑。
- 不引入新的业务状态、抽屉开关或第三方依赖。

## 布局设计

桌面端主体布局采用：

```css
grid-template-columns: minmax(680px, 1fr) clamp(380px, 31vw, 440px);
gap: 12px;
```

含义：

- 地图列至少 680px，剩余空间优先给地图，保证地图仍是主体。
- 右侧详情栏在 380–440px 范围内响应，常见宽屏下约 400px。
- 间距固定为 12px，减少不必要横向浪费。

小屏下切换为上下布局：

- 主体改为单列。
- 地图保持约 520px 最小高度。
- 详情区位于下方，自然高度，避免横向溢出。

## 详情栏设计

- `TieLineDetailPanel` 保持现有卡片容器。
- 内边距从当前较大间距收紧到更适合 400px 右栏的间距，释放图表宽度。
- 标题区允许线路名在必要时换行，电压标签保持右侧固定宽度。
- 线路路径卡片保留。
- 指标卡片仍优先 2 列展示；在窄屏/上下布局下自动退为 1 列。

## 功率趋势设计

- 不改变趋势查询、聚合或响应数据结构。
- 日期按钮区从固定 5 等分改为自适应网格，最小按钮宽度保证文字可读和点击区域充足。
- 图表画布继续使用 100% 宽度，随右栏扩展。
- 图表高度维持 220–240px，避免压缩详情区其他信息。
- 保留加载、空态、错误、重试和自定义日期弹层行为。

## 验证

- 增加/更新前端测试，锁定主体布局、详情面板趋势事件和趋势按钮可点击。
- 运行相关 Vitest。
- 运行 `pnpm build`。
- 启动 `pnpm dev` 检查实际页面布局；若运行环境无法打开浏览器，则报告服务启动结果与可访问地址。
