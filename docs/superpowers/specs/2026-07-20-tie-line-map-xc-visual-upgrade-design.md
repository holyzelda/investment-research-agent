# 联络线地图 XC 工作台视觉升级设计

## 目标

将联络线地图从旧式拼装页面升级为符合 XC 玄策设计体系的深色投研工作台。页面面向投研人员浏览全国跨省跨区联络线，完成筛选、定位线路和阅读静态档案三个高频动作。

本次只做视觉与展示组件重构。路由、接口、Pinia store、props、emit、筛选规则、选中规则、地图交互和后端数据契约均保持不变，调用方零修改。

## 页面结构

页面采用紧凑的工作站阅读流：

```text
页面标题和数据说明                                  四项静态 KPI
──────────────────────────────────────────────────────────────
起点区域  交换起终点  终点区域  额定容量范围  重置筛选
──────────────────────────────────────────────────────────────
┌──────────────────────── 地图主舞台 ────────────────────────┬──── 线路档案 ────┐
│ 地图工具：缩放、复位、全屏、线路列表                        │ 名称、电压标签   │
│ 中国省界、河流、联络线、选中状态、tooltip                   │ 起点至终点路径   │
│ 箭头说明                                                     │ 静态指标栅格     │
│                                                              │ 数据接入说明     │
└──────────────────────────────────────────────────────────────┴──────────────────┘
```

地图是页面唯一主视觉。右侧为固定宽度的静态线路档案面板，承担选中线路和默认推荐线路的阅读任务。顶部 KPI 和筛选条保持紧凑，不挤占地图有效面积。

## 组件职责

### 页面容器

`src/views/tie-line/index.vue` 保持数据加载和组件编排职责。重构为标题区、KPI 区、筛选上下文条和主工作区四部分，使用 XC 间距、字体、边框和 surface token 建立层级。

加载、错误和筛选无结果的既有判断保留。首次加载表现为锁定地图区域尺寸的骨架状态；接口错误在地图区域展示用户可理解的说明与重试入口；筛选无结果由地图与详情区分别呈现明确的空状态。

### 顶部统计

`TieLineStatsBar.vue` 将四项静态统计改为紧凑 XC KPI。每项使用标签、等宽数字和值单位组成，保留原有的联络线数、覆盖区域数、电压等级数、额定容量合计，不补造功率时序指标。

### 筛选上下文条

`TieLineFilterBar.vue` 保持起点区域、终点区域、容量范围、交换和重置的事件契约不变。视觉使用 XC 表单、chip 和 ghost 操作语义：起终点形成连续筛选链路，交换按钮使用 Lucide 图标，容量输入带固定 `MW` 单位，重置为次级操作。

不新增筛选字段，不改变输入校验、不改变范围自动交换逻辑。

### 地图主舞台

`ChinaTieLineMap.vue` 保留 ECharts 地图、底图、河流、线路、透明命中层、静态起讫箭头、缩放、复位、全屏、线路列表和选中逻辑。

地图工具和线路列表统一为 XC glass 上下文层；地图内起讫说明改为低干扰、可读的辅助信息条。地图画布继续使用专属 `--xc-map-*` token，不改变全站 surface token。电压色只表达工程分类，不用作状态或行情语义。

### 线路列表

`TieLineListPanel.vue` 保留现有列表、选择与键盘操作。行样式升级为密集 XC 列表：名称为主、起讫路径和长度为辅助、色标保留电压分类含义；hover、selected 和 focus-visible 状态使用 XC 交互 token。

### 线路档案

`TieLineDetailPanel.vue` 仍接收当前详情、默认推荐线路、无可见线路状态和电压 token。头部突出线路名称、电压和起点至终点路径；字段改为双列密集指标栅格，容量与年份采用等宽数字。

功率趋势不会伪造成图表。它被降级为“功率时序数据未接入”的模块级说明，明确当前仅展示静态线路资料。

## 视觉与交互规则

- 所有颜色、间距、字号、圆角、阴影和动效使用 `var(--xc-*)` token；不保留裸色值和旧 v5 token。
- 中文字体使用 `--xc-font-zh`；数量、容量、年份使用 `.xc-num` 或等宽数字设置。
- 使用 `lucide-vue-next` 替换筛选栏手写 SVG；不引入新 UI 库。
- 普通交互使用 `--xc-accent-blue`，线路电压色仅用于工程分类。
- 页面表面不超过三层，glass 只用于地图工具和地图内列表等上下文层，单屏 glass 层级不超过两层。
- 不增加地图图例、伪造实时潮流、功率数值、趋势图或自动刷新。
- 不改变全屏行为：全屏仅作用于地图，工具、列表和箭头说明随地图保留，右侧详情不进入全屏。

## 数据状态与异常处理

- 首次加载：地图主舞台显示固定尺寸骨架；顶部统计与筛选保持稳定骨架或禁用态，避免布局跳动。
- 刷新：保留可见数据，以轻量 scrim 表示刷新；本次不新增自动刷新入口。
- 失败：地图主舞台显示“联络线数据加载失败，请稍后重试”及重试操作，避免展示后端原始错误。
- 筛选无结果：地图显示“未找到匹配的数据”，详情显示“当前筛选条件下暂无线路”，并提供清空筛选操作。
- 静态详情读取失败：继续使用当前列表基础字段，保持既有 store 降级行为。

## 验证

1. 运行 `pnpm build`，确认生产构建通过。
2. 运行现有前端测试；若测试覆盖页面结构，按新视觉结构更新测试断言，但不更改业务断言。
3. 启动 `pnpm dev`，在 1920×1080 和 1440 宽度下人工验证页面层级、文字适配和地图尺寸。
4. 验证起点、终点、容量筛选，起终点交换和重置；确认筛选后选中线路隐藏时仍清空详情。
5. 验证地图 hover、点击、缩放、复位、全屏、线路列表和键盘选择。
6. 按 XC `design-system.md` §9 P0 与 §10.4 扫描：无裸色值、数字等宽、无 v5 token、无 EP 黑名单组件、glass 层级符合限制。
