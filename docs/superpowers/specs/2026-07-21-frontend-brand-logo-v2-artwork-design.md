# 前端品牌 Logo 替换设计（修订：采用用户第二版参考图）

`docs/superpowers/specs/2026-07-21-frontend-brand-logo-replacement-design.md` 已完成 favicon / 顶部标题栏 / 侧边栏三处统一接入 `/brand-logo.svg` 的落地。该版本内部图形是转绘者自行设计的抽象朱雀图案，用户核对后指出与原图不一致。用户随后提供了自己重新设计的第二版参考图（`C:\Users\JDPC0200\Downloads\image-1784599056702.png`），要求以这版为准重新转绘，并沿用已经落地的三处接入方式。

本设计文档只覆盖**这次的修订范围**：重新转绘 `brand-logo.svg` 的内部图形与 `viewBox`。三处接入点（favicon 链接、顶部标题栏 `<img>`、侧边栏 `<img>`）、资源公共路径 `/brand-logo.svg`、以及"不嵌入位图""不新增依赖""不用浏览器做视觉验收"等约束继续沿用上一版设计文档，不重复展开。

## 参考图内容

竖版构图，白底、无外框：
- 一只朝右侧的鸟形轮廓：主翅膀从头颈处向左上方大幅扫出，末端收尖；主翅下方另有一片小翼羽，带弧形缺口；头顶有一小簇冠羽；喙部为尖角剪影。
- 颈部向下过渡为一道闪电折线，向左下方延伸收尖。
- 闪电右侧是一个直角三角形轮廓，内部被留白切分出三根依次升高的柱状图，柱与柱之间以白色间隙分隔；三角形斜边与闪电的斜切线连成一条视觉上延续的对角线。
- 配色为统一的线性渐变：左上翼尖为亮蓝（约 `#1f7cff`），头颈/闪电中段过渡为蓝紫（约 `#5b4fe0`），右下柱状图区域为紫色（约 `#8b46e8` ~ `#a262f0`）。

## 方案

- **裁切方式**：采用用户已确认的"紧贴图形裁切"——新的 `viewBox` 直接贴合鸟+闪电+柱状图的外轮廓包围盒，不保留参考图上下的大片空白，使其在 favicon、标题栏、侧边栏的方形容器中显示得更大更清晰。
- **绘制方式**：本机没有可用的图像转矢量工具（`potrace`/`imagemagick`/`inkscape` 均确认不可用），采用手工按参考图比例绘制 SVG 路径，逐一还原上述轮廓分组（主翼、下方小翼羽、冠羽、喙、颈部到闪电的过渡、闪电折线、三根柱状图及共用斜切边），用 `<linearGradient>` 还原蓝→紫渐变。
- **保真度预期**：手工绘制无法做到像素级精确复刻，目标是尽量贴近轮廓比例、角度和留白关系；不追求逐点重合。
- **文件与接入范围**：只修改 `agent-frontend/public/brand-logo.svg` 的内部 `<svg>` 内容和 `viewBox` 取值；不改动 `index.html`、`layout/index.vue`、`AppSidebar.vue` 中已经落地的引用方式和样式。
- **测试调整**：`agent-frontend/tests/logo-mask.spec.js` 中原先断言的 `viewBox="0 0 64 64"` 需要更新为新的竖版裁切比例（最终数值以实际绘制结果的包围盒为准），其余断言（无位图嵌入、三处引用同一 URL、无旧 `logo.svg` 残留、欢迎区光球独立不受影响）保持不变。
