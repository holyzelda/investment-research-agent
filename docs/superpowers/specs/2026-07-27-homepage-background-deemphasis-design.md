# 首页欢迎态背景弱化设计

**日期：** 2026-07-27  
**范围：** `agent-frontend` 首页无会话欢迎态的全局背景层

## 目标

降低欢迎态全屏背景图的存在感，使欢迎标题、引导文案与提问输入框成为明确的视觉焦点；左上角 AI 球体及所有前景内容保持原有视觉强度与交互。

## 范围与非目标

- 仅作用于 `src/layout/index.vue` 中、由 `isWelcome` 控制渲染的 `.ir-layout__welcome-backdrop`。
- 仅在首页无会话欢迎态生效；进入对话态、打开历史会话或切换其他路由后，该背景层本来即不渲染。
- 不更改背景图片资源、欢迎态布局、前景组件结构、AI 球体、顶栏、侧栏、导航或任何业务状态。
- 不新增依赖、接口、配置项或运行时状态。

## 视觉方案

采用“深色半透明蒙层 + 轻微模糊”的组合：

1. 保留现有 `var(--xc-grad-atmosphere)` 与背景图片的合成方式和覆盖范围。
2. 使用该背景元素的伪元素创建覆盖整层的半透明遮罩，以既有 XC 深色表面 token 着色，压低图片亮度和局部对比度。
3. 对背景图片所在层施加约 `2px` 的视觉模糊；仍由绝对定位与 `pointer-events: none` 保证不影响前景内容和交互。
4. 前景内容依然位于 layout 的更高层级，因而不受模糊和遮罩影响。

## 实现边界

- 改动限定在 `agent-frontend/src/layout/index.vue` 的 scoped 样式。
- 用 CSS 伪元素承载遮罩，避免新增模板节点或 Vue 状态。
- 样式中使用 XC 设计 token；不添加硬编码色值。
- 遵循既有层级：背景容器保持 `z-index: 0`，顶栏与主体仍在其上层。

## 验收与测试

- 欢迎态：背景图片的内容细节较当前状态明显后退，前景文案、输入框、示例胶囊与 AI 球体保持清晰、不变形且更易聚焦。
- 非欢迎态：背景层不渲染，现有页面外观不变。
- 不影响点击、输入、滚动和导航行为。
- 执行前端相关测试与生产构建，确认 scoped CSS 和 Vue 编译正常。
