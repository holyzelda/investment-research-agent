# 偿债倍数图分段刻度设计

## 目标

将偿债倍数图的 Y 轴改为分段非线性显示轴：`0–1` 区间每 0.5 倍为一个等高网格，超过 1 的区间每 0.2 倍为一个等高网格。通过压缩低于警戒线的视觉高度，避免红色风险区在图中占比过大，同时保留真实偿债倍数的标签和 tooltip。

## 映射

显示坐标使用分段映射：

- `value <= 1`：`display = value / 0.5`；
- `value > 1`：`display = 2 + (value - 1) / 0.2`。

因此真实刻度 `0, 0.5, 1.0, 1.2, 1.4…` 对应连续、等距的显示坐标 `0, 1, 2, 3, 4…`。

后端数据、组件 prop 和 tooltip 均继续使用真实值；仅 ECharts 的 series、警戒线、分区和坐标轴内部采用显示坐标。

## 图表规则

- 根据有效数据中的最大真实值向上取到 0.2 倍边界，生成超过 1 的刻度；无超过 1 的值时最高刻度保持 1.0。
- Y 轴显示坐标以 1 为间隔，label formatter 将其还原为真实倍数并显示一位小数。
- 业务折线将每个非空真实值映射为显示坐标；`null` 保持 `null` 断点。
- tooltip 从原始真实序列读取当前索引的值，显示“第 N 年”和真实倍数；不能显示映射后的坐标。
- 警戒线固定在显示坐标 `2`；红色风险区为 `0–2`，蓝色安全区为 `2–displayMax`。
- 保留玄策品牌蓝主线、圆形数据点、红色虚线警戒线、全宽对齐分区和无常驻点值的规则。

## 测试

测试需覆盖：真实值 `0.5、1.0、1.2、1.4` 映射为 `1、2、3、4`；Y 轴标签还原正确；系列 `null` 断点保留；tooltip 返回真实值；警戒线及红蓝分区使用显示坐标 `2`。
