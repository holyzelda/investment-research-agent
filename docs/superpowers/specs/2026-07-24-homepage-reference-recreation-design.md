# 首页参考图复刻设计

**日期：** 2026-07-24（2026-07-24 修订：顶栏改为更矮、更换集装箱主视觉素材、欢迎区改为左右分栏）

## 目标

重设计 `agent-frontend` 的首页欢迎态，使其以用户提供的 1618 x 972 参考图为桌面视觉基准，同时保留已有测算、会话、报告及导航行为。欢迎态右侧的储能设备主视觉直接采用用户单独提供的高清集装箱素材（`集装箱.png`，1448 x 1086，纯色深底），替换早前从截图粗裁的低清资源，以获得更接近参考图的一致性。

本设计只覆盖前端首页的视觉重构，不改变后端接口、Pinia 数据结构、计算规则或报告数据契约。

## 视觉基准与范围

- 桌面优先，以 1618 x 972 视口作为像素对齐和截图验收的基准。
- 顶栏**收窄**为约 52px（当前实现为 64px，token 记为 88px，均以本次 52px 为准）。它承担品牌、三项概览指标和用户状态展示，且明显低于当前高度，不占用主工作区高度。
- 窄屏不要求复刻工作台比例；现有模块须保持可访问，并允许页面自然滚动；指标条在窄屏可整体隐藏。
- 移除历史会话面板底部的“查看全部历史会话”入口。该入口不得在新实现中渲染。
- 仅欢迎态展示储能设备主视觉；进入会话后保留已有消息流、结果卡片、参数调整与报告入口。

## 布局

### 顶栏

顶栏位于整页顶部，高度约 52px，使用深色半透明工作台背景，采用左品牌 · 中指标 · 右用户的三段式布局。

- 左侧显示现有 `brand-logo.svg`、产品名“朱雀投研智能体”和副标题“ZRA · 储能投资投研助手”。
- 中部显示三项紧凑指标：覆盖省份 `28 个`、生成报告 `256 份`、测算项目数 `128 个`。每项由内联 SVG 图标（定位 / 文件 / 立方体）、小字号标签和数值组成，指标之间以竖细分隔线分隔。数值用 `.xc-num`，字号层级压缩以适配 52px 高度且保持清晰可读。
- 右侧显示现有用户头像、用户名与下拉箭头视觉。保留现有用户信息来源；本次不新增账号菜单行为。
- 三项指标为欢迎页视觉展示数据，使用明确的本地展示配置，不新增后端统计请求。

### 左侧导航与历史会话

左侧仍由图标轨道和历史会话浮层组成。

- 图标轨道继续由 `AppRail.vue` 承担，沿用现有路由及禁用状态，只调整尺寸、背景、圆角、间距和激活光效。
- 历史会话面板继续由 `AppSidebar.vue` 承担，使用深色玻璃面板、细边框和参考图的内边距；根节点带 `data-testid="history-sidebar"` 供回归测试锚定。
- 保留：新建会话、打开历史会话、删除历史会话、折叠及悬浮展开行为。
- 面板中保留品牌行、新建会话按钮、历史会话标题、条目标题和更多操作。
- 不显示任何“查看全部历史会话”按钮、链接或占位区域。

### 欢迎态（左右分栏）

欢迎态仍由 `views/home/index.vue` 控制 `!hasConversation` 分支，布局由当前的整体居中改为左右分栏。

- **左列（交互列）**：自上而下排列现有 AI 球体、渐变问候标题、单行说明、能力标签、`ChatComposer` 输入框和示例指令胶囊。标题与能力标签使用青蓝到紫色的渐变文字；字号、间距、输入框尺寸和胶囊密度以参考图为准。
- **右列（主视觉列）**：放置集装箱储能主视觉（见下）。
- `ChatComposer.vue` 继续管理文本输入、Enter 发送、Shift+Enter 换行、发送中禁用和发送事件。
- 示例指令继续调用当前 `onSend`，复用已有最小输入解析及测算发起流程。
- 窄屏下允许两列自然堆叠或主视觉收窄退让，保证输入组件不被遮挡。

### 主视觉

用户单独提供的高清集装箱素材是主视觉的唯一来源。

- 源文件 `集装箱.png`（1448 x 1086，RGB 纯色深底）落地为项目内资源 `agent-frontend/src/assets/home-energy-storage-hero.png`，替换早前 550 x 470 的截图粗裁图（复用同一文件名）。
- 由于素材是纯色深底、无 alpha 通道，采用 `mix-blend-mode: screen` 让深蓝底自动隐入近黑页面背景，仅保留集装箱与底座光圈的发光部分；辅以轻微径向遮罩柔化边缘，使其在大屏保持参考图构图，并在较窄视口不遮挡输入组件。
- 主视觉作为欢迎区右列的装饰层，位于交互文字与输入框之下的层级，不覆盖左侧会话面板与顶部指标。
- 现有 `ai-sphere.png`、`user.png`、`brand-logo.svg` 保持复用；不重新生成或替换这些资产。

## 数据与交互

- 顶栏用户名继续来自 `session.username`，头像继续使用现有 `user.png`。
- 三项指标为欢迎页视觉展示数据，使用明确的本地展示配置，不新增后端统计请求。
- 历史会话继续使用 `calc.history` 和 `calc.conversationId`；新建、打开和删除事件继续向外发射并由 `layout/index.vue` 处理。
- 欢迎态发送逻辑保持 `onSend -> calc.sendAndCalculate`；发送后进入现有会话态。
- 报告详情跳转、版本选择、结果卡片和参数调整的调用方式不得改变。

## 状态与异常处理

- 欢迎态没有历史会话时，历史区域显示现有空态文案；不以静态示例替代真实数据。
- 用户名缺失时沿用当前“访客”回退。
- 集装箱主视觉加载失败时（`@error`），页面必须仍能正常显示 AI 球体、文案、输入框和示例指令；主视觉层应自然隐藏，不能产生破图图标或阻塞输入。
- 发送中沿用当前 `ChatComposer` 禁用规则；示例指令同步禁用，避免重复发起测算。

## 验收与测试

### 自动化回归

- 保留/更新 `tests/home-welcome.spec.js`：验证欢迎态渲染集装箱主视觉层（`.ir-welcome__energy-hero`）。
- 补充欢迎页测试，验证示例指令仍通过现有发送入口发起测算。
- `tests/layout-sidebar.spec.js`：验证历史面板带 `data-testid="history-sidebar"`，且渲染结构中不存在“查看全部历史会话”。
- 保留现有 `home.spec.js` 的最小输入提取和缺失字段回归覆盖。

### 视觉核验

- 启动前端并在 1618 x 972 视口取得欢迎态截图。
- 对比参考图检查：约 52px 顶栏（明显低于当前）、中部三项指标、左侧轨道和面板位置、欢迎左列垂直节奏、右列集装箱主视觉构图与融合效果、输入框尺寸、示例指令排列。
- 确认所有文字完整可读，主视觉不与输入框、历史面板或顶部指标重叠。
- 确认进入会话后消息流、结果卡片和报告跳转仍可见且可用。

## 非目标

- 不添加新的历史会话总览页面或入口。
- 不新增用户菜单、统计接口、上传功能或移动端专属视觉设计。
- 不将整张参考截图作为不可交互的全页背景。
- 不修改后端代码、数据库结构、API 请求参数或会话数据格式。
