# 隐藏政策与市场研究案卷滚动条设计

## 目标

在政策与市场页面的“研究案卷 / 历史研究记录”列表中移除右侧原生滚动条的视觉显示，同时保留既有鼠标滚轮、触控板、键盘及触摸滚动能力。

## 范围与边界

- 仅修改 `agent-frontend/src/views/policy-market/components/ConsultationHistory.vue` 中历史列表容器的样式。
- 不修改列表高度、布局、数据加载、选中态、历史记录操作或滚动行为。
- 不新增自定义进度条、滚动提示或第三方依赖。

## 方案

继续保留列表的垂直溢出滚动。针对不同浏览器隐藏原生滚动条：Firefox 使用 `scrollbar-width: none`；Chromium/WebKit 使用 `::-webkit-scrollbar { display: none; }`。不设置 `overflow: hidden`，以确保内容仍可访问。

## 验收标准

1. 历史研究记录列表右侧不再显示原生细滚动条。
2. 鼠标滚轮和触控板仍可滚动浏览全部记录。
3. 历史记录数量较多时，现有固定列表区域与页面三栏布局不变。
4. 政策与市场现有组件测试通过。
