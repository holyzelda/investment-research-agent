# 前端品牌 Logo 替换设计

**日期：** 2026-07-21

## 目标

将用户提供的品牌图片转绘为可缩放的 SVG，并在前端所有当前可见的品牌入口统一使用：浏览器标签页图标、首页标题栏和左侧导航栏品牌区域。现有“朱雀投研智能体”文字、布局与交互保持不变。

## 方案

采用单一 SVG 源文件：

1. 基于原始图片重绘为真正的矢量 SVG；不得将 PNG 以 base64 或 `<image>` 形式嵌入 SVG。
2. 将 SVG 放入 `agent-frontend/public/`，作为品牌图形的唯一视觉来源。
3. 浏览器标签页 favicon 指向 SVG；若当前构建或浏览器兼容要求已有兜底资源，则仅将其作为兼容层，不再维护第二套 Logo 设计。
4. 首页标题栏及左侧导航栏引用同一 SVG 资源。仅调整必要的尺寸与对齐样式，保留现有品牌文本“朱雀投研智能体”。
5. SVG 使用适合深色优先 XC 界面的透明背景和清晰的安全留白；图形在 16–32px favicon 尺寸下仍应可辨认。

## 修改边界

- 新增：`agent-frontend/public/` 下的品牌 SVG（以及仅在现有引用需要时的 favicon 兼容资源）。
- 修改：前端 HTML/Vite favicon 引用位置。
- 修改：首页标题栏、左侧导航栏中现有品牌图形的引用及必要样式。
- 不修改：Pinia store、API、路由、业务逻辑、品牌文本、页面交互与其它视觉体系 token。

## 错误处理

资源路径使用 Vite 公共资源的绝对路径引用，避免生产构建后的相对路径失效。若 SVG 无法加载，浏览器将显示其默认 favicon 或空白占位；不增加运行时回退逻辑。

## 验证

- 运行前端生产构建，确保 SVG 资源路径能被正确处理且没有编译错误。
- 运行现有前端测试，确认不影响既有页面行为。
- 浏览器中的视觉核验（标签页、首页标题栏、左侧导航栏）由用户自行完成，本次不自动启动浏览器或截图确认。

## 非目标

- 不从图片中派生或新增架构图、页面插图或其它品牌物料。
- 不重构现有标题栏或导航栏组件。
