# 偿债能力折线图替换设计

## 背景与范围

替换现有“15 年现金流序列”图，不保留四条现金流字段及其前端展示。新图展示“偿债能力｜现金流口径下偿债倍数”。

历史 `report_snapshot` 兼容不在范围内：用户会自行删除旧数据；系统只需支持新结果结构。

## 数据接口与读取

后端允许读取的飞书接口 Sheet 为 `API_OUTPUT` 和 `画图数据`。新增 `画图数据` 是正式读取接口，不要求经由 `API_OUTPUT` 再桥接。

新增一项只读输出参数，读取范围为：

- Sheet：`画图数据`
- 范围：`C3:Q3`
- 含义：现金流口径下偿债倍数
- 单位：偿债倍数
- 类型：`float[]`

飞书网关按参数字典输出项批量读取；对横向范围返回的二维单元格值按行展平为一维序列。

## 领域与结果契约

方案 A：移除旧的四条现金流序列 DTO，新增单序列、语义明确的偿债倍数 DTO，并作为进阶结果的一部分输出。

新报告载荷在 `advanced` 下使用一个专属字段，前端消费的数组表示逐年偿债倍数。该数组元素可为数值或 `null`：

- 数值（包括 `0`）是有效点；
- `null` 表示贷款期中间缺失点，前端必须断线；
- 映射层找到最后一个非空值，裁掉该位置之后的尾部空单元格；
- 如果全部为空，则输出空数组。

例如飞书数据 `[1.3, 1.4, null, 1.2, null, null]` 输出 `[1.3, 1.4, null, 1.2]`，对应第 1 至第 4 年。

## 前端图表

现有现金流组件改为偿债倍数折线图：

- 标题：`偿债能力｜现金流口径下偿债倍数`；
- X 轴标题：`贷款年限`，分类标签为 `第1年` 到序列最后一个有效位置；
- Y 轴标题：`偿债倍数`；
- 业务序列：绿色实线；
- `null` 数据点作为折线断点，不跨越连接；
- 加入固定阈值：`y = 1` 的红色水平虚线；
- 空数组不绘制业务序列。

阈值 `1` 是图表规则，前端通过 ECharts `markLine` 生成，不进入飞书数据或结果 DTO。

## 快照、接口与历史

`report_snapshot` 继续保存前端可直接渲染的 camelCase 结果载荷。任务结果接口和会话历史回放继续原样返回该载荷，无需为新图增加二次转换。

飞书 I/O 快照继续保存参数字典读取后的原始 snake_case 输出，用于追溯。

## 测试

新增或调整测试验证：

1. 参数字典将偿债倍数映射到 `画图数据!C3:Q3`，并标记为只读输出 `float[]`。
2. 飞书网关可以解析“画图数据”Sheet 并将横向范围展平。
3. 输出映射保留 `0` 和中间 `null`，且仅裁剪最后一个非空值之后的尾部空值。
4. 报告载荷输出新的 camelCase 偿债倍数数组，不再输出四条旧现金流数组。
5. 前端生成一条绿色偿债倍数折线、贷款年限 X 轴、偿债倍数 Y 轴和 `y=1` 红色虚线；中间 `null` 保持断线。
