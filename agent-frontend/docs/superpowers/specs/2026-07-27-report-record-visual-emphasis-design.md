# 报告记录定位视觉强化设计

**日期：** 2026-07-27  
**状态：** 已确认

## 目标

统一测算记录和报告记录的报告操作按钮尺寸，并加强“跳转报告记录”后的目标卡片视觉反馈。

## 展示与交互

- 测算记录内的报告操作按钮与报告记录内“查看报告”按钮采用相同的全宽尺寸：占据卡片内容宽度，保持相同最小高度和内边距。
- 定位到目标报告记录后，目标卡片在既有蓝色强调边框与较亮背景之上，增加轻微 token 化外发光和约 1.6 秒的淡入淡出反馈动画。
- 动画结束后自动移除强调状态，保持列表的普通视觉层级。
- 不新增依赖，不增加路由跳转；所有颜色使用 XC CSS tokens。

## 测试

- 组件测试验证测算记录与报告记录按钮均使用同一全宽样式类。
- 定位测试继续验证目标卡片获得强调类；样式规则由该稳定语义类承载，无需断言 CSS 文本细节。
