# 测算记录报告跳转设计

**日期：** 2026-07-27  
**状态：** 已确认

## 目标

优化右侧测算记录的时间层级和报告操作，使已生成报告可在当前右栏内快速定位到对应报告记录，而不离开测算页面。

## 展示与交互

- 测算记录内容顺序固定为：版本状态、项目摘要、项目全投资 IRR、测算时间、报告操作按钮。
- 测算记录的报告操作复用报告记录“查看报告”的 `.ir-report-list__view` 中性灰色按钮样式。
- 无报告时显示“生成报告”；生成中显示禁用的“报告生成中”；生成失败时显示“重新生成报告”。
- 已完成报告时显示“跳转报告记录”，点击后不路由跳转，而是滚动报告记录自身的列表到该测算版本关联的报告卡片。
- 每个报告卡片以 `data-report-id` 提供稳定定位锚点。定位后为目标卡片施加短暂的高亮类，帮助用户识别落点；高亮自动清除。

## 测试

- 组件测试验证测算时间在 IRR 后、按钮文案/样式状态正确。
- 对已完成报告的按钮点击，验证报告列表滚动容器调用目标卡片的 `scrollIntoView`，并为目标卡片添加高亮类。
