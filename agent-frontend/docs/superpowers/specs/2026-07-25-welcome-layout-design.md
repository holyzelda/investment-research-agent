# 欢迎页布局调整设计

## 目标

在不改变现有 XC 深色设计语言、业务交互和页面信息范围的前提下，使首页欢迎态更贴近最新效果图的层级：平台指标位于顶部栏，左对齐的欢迎内容上移至主视觉中上部，输入框位于标题内容下方。

## 范围

- 仅影响首页无会话的欢迎态。
- 将既有五项展示用平台指标从 `Home` 欢迎内容底部移至全局 `Layout` 顶栏中品牌右侧。
- 欢迎内容维持左对齐，删除当前将内容推向底部的布局行为，改为在内容视口的中上部稳定定位。
- 保持标题、说明、能力标签、输入框和示例提示的顺序、文案和交互不变。

## 布局与组件边界

### `src/layout/index.vue`

- 保持现有品牌与用户入口。
- 当且仅当 `route.name === 'Home'` 且 `calc.messages.length === 0` 时，在品牌右侧渲染平台指标栏；用户入口置于该栏最右侧。
- 指标数据仍为展示用本地常量，移至 `Layout`，避免首页组件向全局壳层提供展示数据。
- 顶栏在窄屏下允许指标压缩或换行，不改变既有页面路由、会话、用户资料的加载逻辑。

### `src/views/home/index.vue`

- 删除欢迎内容中的底部指标模板、数据和对应样式。
- 欢迎内容区域保持全宽、左对齐；使用内容区的上部间距与剩余空间控制其位置，不再使用 `margin-top: auto` 贴近底部。
- 背景图继续由 `Layout` 的欢迎态背景层承载；不替换现有资源，不新增新的视觉素材。

## 数据与交互

- 不引入 API 或状态字段。
- 指标继续使用当前五个固定展示值及 SVG 图标。
- `ChatComposer`、示例发送、会话创建、历史侧栏、rail、对话态及报告页均不改变。

## 样式约束

- 全部颜色、圆角、边框、空间、字号、阴影和动效继续使用既有 `--xc-*` token。
- 不引入内联 hex/rgb 颜色，也不将效果图的强发光或额外玻璃拟态带入当前 XC 风格。
- 首页欢迎态才展示指标栏；发起首条会话、打开历史会话或离开首页后恢复当前简洁顶栏。

## 验收

1. 无会话首页：五项指标显示在顶栏品牌右侧，用户入口仍位于最右。
2. 无会话首页：欢迎标题与输入区整体位于主视觉的中上部，且均为左对齐。
3. 有会话首页及非首页：顶部指标栏不显示。
4. 示例发起测算、历史会话、用户展示和响应式布局不回归。
5. 现有前端测试与生产构建通过。
