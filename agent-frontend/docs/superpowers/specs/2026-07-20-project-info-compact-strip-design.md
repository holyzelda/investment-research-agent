# 项目信息紧凑数据条设计

**日期：** 2026-07-20  
**范围：** `ParamAdjustPanel` 的“调整参数并重新测算 → 项目信息”区域。  
**状态：** 用户已确认，待审阅本文档后进入实施计划。

## 目标

减少项目信息卡过大的留白，让省份、节点、装机容量和储能装机功率更像投研工作台中的高密度项目摘要，同时保持 XC 深色层级与既有可编辑行为。

## 设计

- 保持项目字段顺序、显示条件和响应式换行规则不变：省份、存在站点时的节点、容量、功率。
- 将项目字段卡从 72px 最小高度收紧到 56px；上下内边距从 12px 收紧到 6px。
- 字段标题保留为 12px 的静默标签。
- 只读字段值提高到 16px；容量和功率的可编辑数值提高到 18px，并保留等宽数字展示语义。
- 保留左侧青蓝强调线，但让卡面背景更低调，使注意力集中于项目值。
- 容量和功率的输入编辑行为、悬浮/聚焦底部 accent 提示、节点下拉、锁定规则、参数字典驱动和重新测算 payload 均不变。
- 窄视口继续沿用现有两列换行规则，不新增横向滚动。

## 非目标

不调整金融、收益、成本参数区；不改变参数范围、精度、可编辑性、字典字段、接口、状态管理或测试业务断言。

## 自检

本文档没有未决占位项；视觉调整只影响项目字段卡的尺寸、文本层级与 token 化外观，且不改变任何业务或交互契约。
