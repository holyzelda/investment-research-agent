# 全国指数地图设计规格

## Design Read

像一张正在使用的投资态势制图台：地图负责建立全国视野，统计条提供判断基线，右侧卷宗解释当前省份；专业、安静、密集且易扫描。

## 设计承诺

- 绑定 `.ulpi/design/DESIGN.md`，不新增第二套色彩、字体、间距、圆角或动效。
- 页面 Signature 为“制图基准网格 + 当前省份精确描边”，仅作用于地图主舞台。
- 地图是第一视觉层级；省份详情为第二层级；统计与榜单为支持层级。
- 禁止玻璃拟态、霓虹外发光、紫蓝渐变、装饰光球、渐变字、嵌套卡片和营销式大标题。
- S/A/B/C 色彩只表达数据等级，不扩散为界面主题色；青蓝为唯一交互强调色，琥珀只表达风险或等级提醒。
- 反事实检验：该页面的制图网格、坐标语义、地图主舞台和省份卷宗结构只服务全国投资指数研判，不是通用仪表盘模板。

## 用户流程

1. 用户进入页面，系统加载可用期次并默认选择最新一期。
2. 全国概览加载后，地图、统计条和双列榜单同时呈现，并默认选择领跑省份。
3. 用户可切换期次；切换时保留可用的省份选择，否则回到该期领跑省份。
4. 用户点击地图省份或榜单条目，地图更新精确描边，右侧卷宗加载对应详情。
5. 用户可缩放、复位或全屏地图；退出全屏后保持当前选中省份和视图语义。
6. 请求失败时在所属区域原位重试，不清空其他已成功区域。

## 状态模型

| 状态 | 表现 | 操作 |
|---|---|---|
| 加载期次 | 工作栏期次控件禁用并显示加载语义 | 无 |
| 加载概览 | 地图主舞台显示克制的骨架/加载状态，布局尺寸不跳动 | 等待 |
| 加载详情 | 右侧卷宗保留稳定框架，内容区显示加载状态 | 可继续操作地图 |
| 空数据 | 地图区域说明当前期次暂无全国指数，统计与榜单显示空值而非伪数据 | 切换期次 |
| 部分成功 | 地图和榜单可用、详情失败时，仅右栏显示错误；反之亦然 | 分区重试 |
| 错误 | 对应区域使用危险语义色、简短原因和“重试”命令 | 重试 |
| 成功 | 地图、统计、榜单和省份卷宗数据一致 | 浏览与切换 |
| 离线/会话失效 | 沿用全局请求层处理；本页保留稳定布局，不展示未经确认的数据 | 全局恢复后重试 |

## 页面结构

- 顶部工作栏：页面名、简短业务范围、当前期次选择。标题保持紧凑，不做 Hero。
- 主体左区：地图主舞台，上方/下方按可用高度组织统计条；地图必须获得最大连续面积。
- 左区底部：双列排行表，共享同一外框与表头基线，以细分隔线区分两类榜单。
- 主体右区：宽度 `340-380px` 的省份分析卷宗，显示省份、等级、排名、指标与结论。
- 地图图例与工具条属于地图内部操作层，使用平面实色和细边框。

## 响应式

- `>= 1280px`：两列主体，右栏 `clamp(340px, 25vw, 380px)`；页面在可用视口内工作。
- `1024-1279px`：右栏约 `330px`，统计条允许紧凑换行，榜单仍双列。
- `< 1024px`：自然纵向滚动，右栏移到地图和榜单之后；地图稳定高度 `clamp(420px, 56vh, 620px)`。
- `< 640px`：单列；标题与期次控件换行；地图高度约 `420px`；统计为两列；榜单改为上下排列；详情为自然高度。
- 所有按钮触控尺寸至少 `44x44px`；动态文本不可改变工具条、统计单元或榜单列宽。

## 组件规格

### IndexPeriodSelect

- 目的：切换全国指数期次，展示当前周期。
- 状态：默认、悬停、聚焦、禁用、加载、无期次。
- 交互：选择后触发 `selectPeriod`；不得增加额外确认步骤。
- 可访问性：显式标签“指数期次”，键盘可操作，焦点环使用 accent。

### ChinaIndexMap

- 目的：建立全国空间分布认知并选择省份。
- 视觉：平面深色主舞台，低对比制图网格；省界清晰；选中省份使用 accent 精确描边，不使用阴影发光。
- 状态：加载由父级承载；空数据保留中国底图与未覆盖图例。
- 交互：点击选择；滚轮/拖拽沿用 ECharts；工具条提供放大、缩小、复位、全屏。
- 可访问性：容器有地图说明；工具按钮具备名称和 tooltip；键盘焦点清晰。

### IndexSummaryCards

- 目的：提供全国判断基线。
- 形态：改为单一横向统计条，单元之间用分隔线，不使用四张独立卡片。
- 内容：核心数字、短标签、必要的等级语义；空值显示 `—`。
- 响应式：桌面四列，手机两列；数值使用等宽数字。

### IndexRankingList

- 目的：比较投资热力和收益稳定性并快速定位省份。
- 形态：两个列表共享紧凑排行区域；行高稳定，排名、名称和数值对齐。
- 状态：默认、悬停、选中、空；选中仅使用左侧 accent 线和轻量底色。
- 可访问性：行使用按钮语义；支持 Enter/Space；选中状态可被读屏识别。

### ProvinceIndexDetail

- 目的：解释当前省份的等级、排名、分项指标与研究提示。
- 形态：平面卷宗侧栏，以区段标题和分隔线组织，不做大面积渐变玻璃卡。
- 状态：加载、错误、空选择、成功；错误仅影响本栏。
- 可访问性：加载使用 `aria-live`，指标标签与数值关联，颜色不作为唯一信息载体。

### IndexMapToolbar

- 目的：地图视图控制。
- 图标：统一使用 `@lucide/vue` 的 `ZoomIn`、`ZoomOut`、`LocateFixed`、`Maximize2/Minimize2`。
- 形态：44px 方形图标按钮，实色背景、1px 边框、4px 圆角；每个按钮有 tooltip 和 `aria-label`。

## 可访问性

- 正文与背景对比至少 4.5:1，大文本至少 3:1；边界和焦点至少 3:1。
- 所有交互均可通过键盘完成，焦点顺序遵循工作栏、地图、榜单、详情。
- 不以 S/A/B/C 颜色单独传达等级，始终同时显示文字。
- 动态状态使用简短文本和适当 `aria-live`；加载时不造成布局偏移。
- `prefers-reduced-motion` 下关闭位移和强调动画。
