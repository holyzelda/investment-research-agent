# 联络线地图地理资产说明

## `china.json`

中国省级行政区底图。该文件是地图的行政区边界表达来源；新增自然地理要素只能作为背景叠加，不得改写其国界、行政区或南海诸岛表现。

## `china-major-rivers.json`

- **用途**：联络线地图的低干扰河流背景，仅作物理地理示意，不提供导航、测绘、国界或行政区划依据。
- **上游来源**：Natural Earth Vector，`ne_50m_rivers_lake_centerlines`。
- **许可证**：Public Domain（公有领域）。
- **数据版本与下载日期**：Natural Earth Vector GitHub `master` 分支，2026-07-17 下载。
- **处理方式**：仅保留中国范围内具有全国尺度识别意义的主要河流要素（长江、黑龙江、雅鲁藏布江、松花江、塔里木河、辽河、西辽河、海拉尔河等）；移除非必要属性，保留最终 GeoJSON，不提交完整全球源数据。
- **渲染约定**：以静默、无 tooltip、无动画的冷色细线绘制在业务联络线下方；颜色与透明度通过 `--xc-map-river*` token 提供。

> Natural Earth 的公有领域状态只处理河流数据版权问题，不替代中国地图对外发布的审图、边界表达和内容审核。对外发布前应由负责团队复核现有底图及新增背景图层的合规性。
