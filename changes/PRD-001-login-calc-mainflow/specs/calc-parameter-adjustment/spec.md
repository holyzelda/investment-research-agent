# 能力规格：calc-parameter-adjustment（参数调整与重新测算）

> 来源：PRD US-1.3。inline 调整区、锁项规则、收益类显隐、多版本重算。

## ADDED Requirements

### Requirement: inline 参数调整区

The system SHALL 在结果下方提供"调整参数"模块，inline 展开、**默认收起、点击展开**；数值类参数用**滑块**（带默认值与范围），可枚举参数用**下拉**（省份、节点、经营年限、贷款年限等）。基本信息模块已展示的"充电成本/放电返还/损耗费用"在调整区不重复显示。

#### Scenario: 默认收起

- **WHEN** 结果首次展示
- **THEN** 调整参数模块默认收起，点击后 inline 展开

### Requirement: 参数分区

The system SHALL 将展开后的参数按区组织：项目定义（首次锁定区）/ 金融边界（EPC单价、贷款利率、贷款年限、经营年限）/ 收益边界（现货充放均价、日均充放电次数、及按省显隐的中长期/调频/干预/租赁等）/ 成本边界（换电成本、维保成本、运营成本）。

#### Scenario: 分区展示

- **WHEN** 展开调整区
- **THEN** 参数按项目定义/金融边界/收益边界/成本边界分区展示

### Requirement: 可调性与锁项规则

The system SHALL 按测算次序控制可调性：**首次测算**时省份/节点/功率/容量 🔒 锁定只读，其余参数按映射表 G 列（G=1 可调 / G=0 只读）；**二次及以后**省份/节点/功率/容量解锁可改，其余仍按 G 列。

#### Scenario: 首次锁定

- **GIVEN** 首次测算结果已出
- **WHEN** 展开调整参数
- **THEN** 省份/节点/功率/容量只读，其余可调参数按 G 列可编辑

#### Scenario: 二次解锁

- **WHEN** 在已有结果基础上再次进入调整区
- **THEN** 省份/节点/功率/容量变为可改

### Requirement: 收益类条件显隐

The system SHALL 对收益类参数按省份在表2的开关（=1）决定是否展示可改：**现货始终展示**；中长期、调频、干预补偿、容量补偿、租赁按表2开关显隐；改省份后由后端重拉表2并重算显隐。

#### Scenario: 收益类显隐

- **GIVEN** 省份=甘肃（表2：现货1/调频1/中长期0/租赁0）
- **WHEN** 展开收益边界
- **THEN** 展示现货、调频参数，不展示中长期、租赁参数

#### Scenario: 改省份重算显隐

- **WHEN** 用户把省份改为另一省并触发重拉
- **THEN** 后端按新省表2 返回新的显隐集合，前端据此更新可见参数

### Requirement: 重新测算生成新版本

The system SHALL 在用户点"重新测算"时生成**新任务、新版本**（V2/V3…），不覆盖旧结果；每次测算的接口入参在确认后冻结；新版本在右侧版本记录追加。

#### Scenario: 二次解锁并重算

- **WHEN** 用户改省份/功率并点"重新测算"
- **THEN** 生成新版本 V2，旧版本 V1 保留，收益类显隐按新省份重算
