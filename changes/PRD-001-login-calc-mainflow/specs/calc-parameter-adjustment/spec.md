# 能力规格：calc-parameter-adjustment（参数调整与重新测算）

> 来源：PRD US-1.3。inline 调整区、锁项规则、收益类显隐、多版本重算。

## ADDED Requirements

### Requirement: inline 参数调整区

The system SHALL 在结果下方提供"调整参数"模块，inline 展开、**默认收起、点击展开**；数值类参数用**滑块**（带默认值与范围），可枚举参数用**下拉**（省份、节点、经营年限、贷款年限等）。基本信息模块已展示的"充电成本/放电返还/损耗费用"在调整区不重复显示。

#### Scenario: 默认收起

- **WHEN** 结果首次展示
- **THEN** 调整参数模块默认收起，点击后 inline 展开

### Requirement: 参数分区

The system SHALL 将展开后的参数按区组织：项目定义/ 金融边界（EPC单价、贷款利率、贷款年限、经营年限）/ 收益边界（现货充放均价、日均充放电次数、及按省显隐的中长期/调频/干预/租赁等）/ 成本边界（换电成本、维保成本、运营成本）。

#### Scenario: 分区展示

- **WHEN** 展开调整区
- **THEN** 参数按项目定义/金融边界/收益边界/成本边界分区展示

### Requirement: 可调性与锁项规则

The system SHALL 控制参数可调性：省份在参数调整区永久锁定，修改省份必须新建会话并重新提问；节点/功率/容量在首次结果及后续结果均可改，其余参数按映射表 G 列（G=1 可调 / G=0 只读）。项目运营期仅在既有高级参数弹窗中以参数字典驱动的下拉框提供 15 年、20 年两个选项，暂存后以 `param_overrides.operation_years` 随重算提交；换电成本固定 0；贷款年限因参数字典/底稿尚无映射，本阶段不展示。

#### Scenario: 项目参数编辑

- **GIVEN** 首次测算结果已出
- **WHEN** 展开调整参数
- **THEN** 省份永久只读，节点/功率/容量可编辑，其余可调参数按 G 列可编辑

#### Scenario: 后续版本保持可编辑

- **WHEN** 在已有结果基础上再次进入调整区
- **THEN** 节点/功率/容量仍可改，省份仍只读；换省需新建会话

### Requirement: 收益类条件显隐

The system SHALL 对收益类参数统一按省份在表2的市场开关（=1）决定是否展示可改：现货、中长期、调频、干预补偿、容量补偿、租赁均按各自开关显隐；省份在当前会话中不可修改，换省通过新会话重新提问并由后端读取新省表2。

#### Scenario: 收益类显隐

- **GIVEN** 省份=甘肃且表2开关为：现货1/调频1/中长期0/租赁0
- **WHEN** 展开收益边界
- **THEN** 展示现货、调频参数，不展示中长期、租赁参数；若现货开关为0则现货参数也不展示

#### Scenario: 换省新建会话

- **WHEN** 用户希望修改省份
- **THEN** 当前调整区保持省份只读，用户须新建会话并重新提问，后端按新省表2返回新的市场显隐

### Requirement: 现货电价依赖重算

The system SHALL 在重新测算时由后端比较上一版本 input_snapshot 与本次完整输入中的现货依赖项【节点、容量、功率、日均充放电次数】：任一依赖变化时，后端 SHALL 忽略面板传入的旧现货充/放电价，按最新依赖重新查询预计算表并以新价格对覆盖后落入本次 input_snapshot；依赖均未变化时，后端 SHALL 不查询预计算表，继承上一版本完整现货价格对并应用用户本次手工修改。省份在会话内永久锁定；现货市场开关为0时不展示现货参数且不查询预计算表。现有现货单位标注和换算逻辑本批次不得修改。

#### Scenario: 依赖变化重新查询

- **GIVEN** V2 以 V1 为基础调整参数
- **WHEN** 节点、容量、功率或日均充放电次数至少一项变化
- **THEN** 后端重新查询预计算表，以最新充/放电价覆盖面板旧值并写入 V2 input_snapshot

#### Scenario: 仅手工调整电价不查询

- **GIVEN** 节点、容量、功率、日均充放电次数均与上一版本相同
- **WHEN** 用户修改现货充电价或放电价并重新测算
- **THEN** 后端不查询预计算表，使用上一版本完整价格对叠加本次手工修改

#### Scenario: 后续版本继承手工电价

- **GIVEN** V2 已手工修改现货电价
- **WHEN** V3 相对 V2 未改变现货依赖项且未再次修改该电价
- **THEN** 后端不查询预计算表，V3 继续使用 V2 的现货价格对

### Requirement: 重新测算生成新版本

The system SHALL 在用户点"重新测算"时生成**新任务、新版本**（V2/V3…），不覆盖旧结果；每次测算的接口入参在确认后冻结；新版本在右侧版本记录追加。

#### Scenario: 修改项目参数并重算

- **WHEN** 用户修改节点或功率并点“重新测算”
- **THEN** 生成新版本 V2，旧版本 V1 保留；若节点或功率变化，现货电价按最新依赖重查
