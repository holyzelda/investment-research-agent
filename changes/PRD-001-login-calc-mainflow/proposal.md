## 背景（Why）

朱雀投研智能体（ZRA-3）是面向储能投资投研的**独立**内部智能体，作为**统一平台的子应用**（同域部署、由平台首页统一入口进入）。一阶段目标是打通"**首页对话 → 飞书副本测算 → 结果三模块 → 快照/版本**"主闭环，供内部 3–5 人低频使用。

储能财务测算公式极其复杂（15+ sheet、XLOOKUP/IRR/NPV、层层依赖），底稿由业务方在**飞书**维护。本系统**不重写公式**，通过飞书 API 对底稿副本"写参数 → 触发重算 → 读结果"，把飞书作为唯一权威计算器。

**阶段0 关键定性（随 PRD 变更）**：登录、注册、图形验证码、用户管理、角色/权限（RBAC）**全部由统一平台首页负责，本系统不实现**。用户在平台首页完成统一登录后，点击进入本系统 → 跳转承接 → 直接落到**对话首页**。身份透传采用**已定原则**：平台/网关将用户标识**注入到转发给本系统的请求头**，本系统后端**直接信任并读取 header 中的 user_id / username**（仅用于快照 `conversation` 归属），**不自建登录、不做 token 二次校验、不依赖任何外部登录态存储**。

**技术定位**：前端整体风格对齐 trader 的 **XC 玄策设计体系**（trader 仅作**前端设计借鉴**），与平台观感统一，**不单独设计登录/用户/权限界面**；后端采用**团队统一后端栈**（FastAPI + SQLAlchemy 异步 MySQL + Nacos），**仅框架选型一致，不参考 trader 的业务/鉴权代码**。MySQL 新库 `ir_agent`。

现在需要交付：可演示的平台承接落地 + 测算主链路，验证飞书测算方案（方案A · 独立接口区）的可行性。

## 变更内容（What Changes）

- **新建前端应用** `agent-frontend/`：全新 Vite + Vue3 工程，引入 `src/design-system/`（XC 玄策：`--xc-*` token、`.xc-*`、Element Plus 覆盖、CHARTS.md），复用通用框架层（请求层、布局、路由、通用组件、svg-icon、nprogress）。**无独立登录页**；入口为平台首页跳转，落地页即"对话首页"。品牌为"朱雀投研智能体"，视觉与平台/trader 统一。
- **新建后端应用** `agent-backend/`：团队统一栈 FastAPI 应用工厂、Nacos 配置装载、请求日志中间件、异步 SQLAlchemy 会话、`{code,msg,data}` 响应壳与异常处理；新增**平台身份读取**与测算领域模块。
- **平台接入与承接（阶段0）**：承接平台首页跳转到对话首页；后端以轻量中间件/依赖从请求头读取 `user_id/username`（header 字段名可配，默认待与平台约定），注入 `request.state`，供快照归属；**不做**登录页、注册、验证码、用户管理、RBAC、token 校验。
- **参数字典与飞书映射（数据契约）**：产出参数字典（F=1 输入项 + 表2《各省收益结构》范围），约定飞书接口区 `API_INPUT/API_OUTPUT/API_META` 结构与桥接公式契约。
- **测算执行链路**：飞书副本复制 → 写接口区 → 轮询等算 → 读结果 → 校验 → 7 类快照落 `ir_agent`；智能重试（可/不可重试区分，最多 3 次）。
- **首页对话与结果三模块**：最小三项（省份/容量/功率）自然语言输入 → 自动补齐参数 → inline 返回基本信息 / 财务指标 / 进阶图形（环形图 + 折线图）。
- **历史会话列表与回放**：左侧“投资分析工作台”全部功能项之后展示当前用户历史会话；用户手动查看会话并回放固定顺序消息、测算版本与 report_snapshot 结果；通过“…”菜单二次确认软删除，只从列表隐藏，任务和快照继续保留。
- **参数调整与重新测算**：inline 调整区（滑块+下拉、省份锁项、节点/功率/容量可编辑、收益类按表2显隐），重算生成新版本（V1/V2/V3），右侧版本记录常驻。
- **报告本体、中台 Tool、地图模块**：仅保留"生成报告"入口占位与版本记录，**不实现报告本体**。

## 能力（Capabilities）

### 新增能力

- `frontend-scaffold` — 全新 Vue3 工程：XC 玄策设计体系 + 通用框架层 + 朱雀品牌化，无独立登录页、落地对话首页。
- `backend-scaffold` — 团队统一栈 FastAPI 后端基座（Nacos + 异步 MySQL `ir_agent` + 响应/异常/日志骨架）。
- `platform-access` — **平台接入与承接**：承接平台跳转落地对话首页；后端从请求头读取 user_id/username 用于快照归属；不做登录/用户/权限。
- `calc-parameter-dictionary` — 参数字典与飞书接口区映射（数据契约、四来源、F=1+表2 收敛）。
- `calc-execution-engine` — 飞书副本测算执行链路（状态机）、智能重试、7 类快照与版本记录。
- `calc-conversation` — 首页对话最小输入触发测算、结果三模块展示、历史会话列表与回放。
- `calc-parameter-adjustment` — 结果内 inline 参数调整与重新测算（多版本、锁项/解锁、收益类显隐）。

### 修改能力

- 无（全新仓库，无既有能力被修改）。
